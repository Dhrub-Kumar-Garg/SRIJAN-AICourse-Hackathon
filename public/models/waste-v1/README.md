# Srijan material model — waste-v1

This model predicts the nine existing app categories using a **new trained classification head** on frozen MobileNet v2 alpha 1.0 features. It replaces the original ImageNet-label keyword mapper in photo classification. Domain types, store and route selectors are unchanged. Every suggestion requires user confirmation.

## Training and data

- Frozen feature backbone: the original Google TF Hub MobileNet v2 1.0 / 224 checkpoint used by `@tensorflow-models/mobilenet` 2.1.1. Its weights are unchanged. TensorFlow.js model software: https://github.com/tensorflow/tfjs-models/tree/master/mobilenet (Apache 2.0; accompanying notice retained).
- New head: 1,280 features → Dense 128 with ReLU and L2 0.0005 → training-only dropout 0.3 → Dense 9 logits. Adam 0.0005, batch 64, class-balanced loss, seed 20261025, training-only horizontal flips. Validation-loss early stopping with patience 10 selected epoch 26 from 36 epochs. Feature layers were not fine-tuned.
- **RealWaste**, Single, S.; Iranmanesh, S.; Raad, R. (2023), UCI Machine Learning Repository, DOI https://doi.org/10.24432/C5SS4G . UCI lists CC BY 4.0; upstream authors' repository lists CC BY-NC-SA 4.0. Both notices are preserved in `/evaluation/ATTRIBUTION.md`. The licensing discrepancy remains unresolved; model distribution does not resolve it.
- **Custom Bangladeshi E-Waste Image Dataset for Object Detection and Recognition**, Afrin, Tanzila; Azmi, Azizul Abedin (2025), Mendeley Data V1, DOI https://doi.org/10.17632/77383kmdnw.1 , CC BY 4.0. Source: https://data.mendeley.com/datasets/77383kmdnw/1 . The provided archive is a Roboflow YOLO/segmentation export with source-generated augmentations and train/valid/test partitions. The archive's README and `data.yaml` confirm CC BY 4.0. Label polygons supply image-level categories only when all annotations use a single supported source class. No label is generated by our classifier.
- RealWaste Cardboard/Paper → paper; Food Organics/Vegetation → organic; Glass/Metal/Plastic/Textile Trash/Miscellaneous Trash → corresponding app categories. E-waste Keyboard/Mobile/Mouse/PCB → ewaste; Battery_Waste → hazardous; Glass_Waste/Metal_Waste/Organic_Waste/Paper_Waste/Plastic_Waste → corresponding materials. Medical_Waste, Light_Bulb and mixed-class images are omitted because their image-level routing labels are ambiguous.

## Data separation

4,031 retained training images, 674 validation images, 818 held-out test images, and the original 99-photo benchmark. Training counts include source-authored augmentation variants. Byte hashes, source-original filenames and dHash Hamming distance ≤4 form duplicate groups. Conflicting-label groups are excluded. Original benchmark images and their neighbours are reserved. RealWaste group buckets use a fixed SHA-256 split; e-waste source partitions are preserved, with test taking precedence if a group overlaps. Validation/test retain one representative per group. A public manifest records every source path, class, hash, group and split.

Only validation chooses the checkpoint, score temperature and review thresholds. The 818 held-out test images and 99-photo benchmark do not influence those choices. Physical-object identities are unavailable; heuristic duplicate grouping cannot guarantee absence of every related image.

## Measured results (25 October 2026)

| Set                           | Top-1 accuracy  | Accepted-suggestion accuracy | Coverage        |
| ----------------------------- | --------------- | ---------------------------- | --------------- |
| Held-out test, all 9 classes  | 691/818 (84.5%) | 689/810 (85.1%)              | 810/818 (99.0%) |
| Original benchmark, 7 classes | 86/99 (86.9%)   | 86/99 (86.9%)                | 99/99 (100%)    |

The selected review policy is score ≥0.35, margin ≥0, temperature 1.7. These values come from a fixed validation-only search maximizing coverage with ≥30 accepted suggestions and ≥80% validation suggestion accuracy. Scores are not proof of composition or safety. Earlier results are archived at `/evaluation/legacy-report.json`; comparisons must distinguish top-1 accuracy from success after abstention.

The exact app inference function was independently run through TensorFlow.js CPU on all 99 benchmark photos: 86/99 correct, with every top-1 prediction matching native TensorFlow and maximum score difference 0.000022. `tfjs-verification.json` preserves the measured outputs and model hashes. Browser decoding and WebGL may introduce further small differences; no independent field accuracy is established.

## Deployment and limitations

`base/model.json` and `base/weights.bin` hold the unchanged feature graph; `head.bin` holds four float32 tensors (shapes in `metadata.json`). SHA-256 hashes identify the exact artifacts. RGB images use natural dimensions, normalization to [0,1], and bilinear resize to 224 with `alignCorners=true`. Head logits use temperature-scaled softmax. The app downloads static artifacts from its own origin and performs inference locally; no prediction API or photograph upload is required.

These are **same-source public dataset results**, not independent local or municipal validation. Background, source and augmentation cues can bias performance. Hazardous examples cover batteries only (17 held-out test images); chemical, medical and other hazardous items are not validated. The model cannot establish contamination, mixed composition, toxicity or real facility acceptance. Out-of-distribution images can receive confident wrong labels. Human confirmation and manual catalog selection remain essential.

See `training-report.json` for per-class precision/recall/F1 and the confusion matrix, `heldout-results.json` for source-labelled predictions, `history.json` for optimization history, and `split-manifest.json` for leakage auditing. Reproduction commands are in the repository README.
